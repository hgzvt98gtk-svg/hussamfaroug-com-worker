# Security Policy

## Supported Versions

Security fixes target the current `main` branch. Older snapshots are not maintained.

## Reporting a Vulnerability

Report vulnerabilities privately to admin@hussamfaroug.com. Include affected
paths, reproduction steps, prerequisites, and impact, but omit real credentials
and personal data. Do not publish exploit details in a public issue before
coordinating disclosure with the maintainer. Response times are not guaranteed.
